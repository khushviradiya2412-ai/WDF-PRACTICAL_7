## Practical 6: External JSON Data Explorer

Open `PAGES/DATA-EXPLORER.HTML` through a local web server to view the completed Practical 6 work. It fetches and renders the following external JSON files from `DATA/`:

- `events.json` — 15 campus event records
- `students.json` — 15 student profile records
- `faqs.json` — 15 FAQ records

The explorer is split into `JS/data-service.js` (Fetch API, JSON parsing, and localStorage cache) and `JS/data-explorer.js` (rendering and UI logic). It provides loading and error states, text search, category filters, country/state/city dependent dropdowns, sorting, pagination, and cached offline-like display when a prior response is available.
